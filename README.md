# Ricardo Zamboti
**Desenvolvedor Front-end | Especialista em Automação & Infraestrutura**

Profissional de tecnologia com sólida experiência na intersecção entre desenvolvimento web e operações de infraestrutura. Foco na criação de interfaces eficientes e na arquitetura de soluções automatizadas de alta disponibilidade. Busco constantemente otimizar processos, reduzir gargalos operacionais e garantir a segurança dos dados.

### 💻 Principais Competências

- **Desenvolvimento & Web:** Construção de interfaces responsivas e otimização para motores de busca (SEO).
- **Automação & Cloud:** Criação de pipelines de sincronização e backup (AWS) utilizando rsync e Git Bash.
- **Segurança:** Implementação de rotinas de autenticação seguras baseadas em chaves SSH.
- **Monitoramento:** Configuração de telemetria avançada e análise de performance de banco de dados (Zabbix).
